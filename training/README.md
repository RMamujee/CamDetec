# Training the CamDetec rodent model

COCO-SSD (the default detector) recognizes ~80 general classes but **not**
rodents. `train_pest_model.ipynb` trains a purpose-built **rodent** detector that
drops into the app through the `Detector` seam (`lib/detector.ts` →
`YoloTfjsDetector`) with **no app code changes** — install the export under
`public/models/pest/` and pick it in Settings.

## TL;DR — it's free

Open **`train_pest_model.ipynb`** in **Google Colab** with a free T4 GPU and Run
all. It's wired to a specific Roboflow workspace's three rodent datasets, merges
them, collapses everything to a single `rodent` class, trains YOLOv8n, and exports
a `rodent_model.zip` you unzip into `public/models/pest/`.

- **Compute:** free Colab T4 (~30–90 min).
- **Data:** the three Roboflow rodent datasets (versions auto-generated by the
  notebook in Colab). Edit `WORKSPACE` / `PROJECTS` in the download cell to use
  different datasets.
- **Serving:** $0 — the model runs in-browser, it's just static files on Vercel.

## Key handling

The notebook reads the Roboflow key from a **Colab secret** named
`ROBOFLOW_API_KEY` (🔑 icon in Colab's sidebar). The key is never written into the
notebook or the repo. Rotate it in Roboflow whenever you like.

## Why YOLOv8 + single class

Ultralytics YOLOv8 is the most reliable free-notebook path (one-line install/
train, first-class `export(format="tfjs")`). `yolov8n` is small enough for the
browser. Collapsing the datasets' mixed/messy class names to one `rodent` class
gives a cleaner, stronger detector than fighting inconsistent labels.

## Install the result

1. Unzip `rodent_model.zip` → `model.json`, `group1-shard*.bin`, `labels.json`.
2. Copy all into `public/models/pest/`.
3. `vercel --prod` (or commit + push).
4. App → **Settings → Object model → "Pest model · YOLOv8"**.

If the model isn't installed, selecting it fails gracefully and the app stays on
COCO-SSD (motion detection still flags off-vocabulary pests by movement).

## Files

- `train_pest_model.ipynb` — the training + export notebook (Colab).
- `labels.example.json` — label-order example (single `rodent` class).
- `requirements.txt` — deps if you'd rather run it locally with a GPU.
